## Usage Notes

- Variables prefixed with `g_` are global variables (defined in `game/globals.gd`)
- Variables prefixed with `S.` are instance variables (defined in `game/gm_vars.gd`)
- The Polish names are preserved for compatibility with the generated code
- English comments have been added to variable declarations for readability
